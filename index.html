第一次執行時，Windows 跳警告？

這是 Windows 對未簽章程式的預設行為，請依以下步驟通過

📌 為什麼會跳警告？

Windows 對「沒有付費購買數位簽章」的程式會顯示「Microsoft Defender SmartScreen 已防止無法辨識的應用程式啟動」訊息。 這是 Windows 對新程式的預設保護，並不代表本程式有問題。

我們是個人開發者，數位簽章費用每年約 NT$3,000-12,000，目前尚未購買。 累積足夠下載量後，Microsoft 會自動建立信任，警告就會消失。

補充：並非每台電腦都會跳警告。是否跳警告取決於該電腦的 SmartScreen 設定與這個程式在該電腦上的下載歷史。

✅ 通過警告的方法（10 秒）

  1. 看到「Windows 已保護您的電腦」視窗時，不要直接點關閉
  2. 點視窗中的「更多資訊」
  3. 視窗會展開，下方出現「仍要執行」按鈕
  4. 點「仍要執行」即可正常安裝

ⓘ 只需要做一次。之後再執行同個程式，Windows 會記住您的選擇。

🛡️ 自己也想驗證安全？

您可以把下載的 EXE 上傳到免費病毒掃描網站 VirusTotal.com， 會用 70+ 種防毒引擎同時掃描。

極少數防毒可能對 PyInstaller 打包的程式誤報（因為打包機制類似某些惡意軟體）， 這是 PyInstaller 已知議題。若有疑慮歡迎來信 linebooks2026@gmail.com。
